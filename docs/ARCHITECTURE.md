# FuckLike — Full System Architecture

Everything ships together. No phasing.

## Layers

### 1. Companion Core (Web / App)
- Deep character creation
- Ready-made gallery + filters
- Persistent multi-tier memory
- Text chat, images, voice, short video
- Relationship progression + scenarios
- Multi-companion chat
- Free + paid tiers
- Intensity controls
- 18+ hard gate

### 2. Spatial / 3D (Godot 4)
- Third-person presence
- Private persistent spaces
- High-quality lighting (tps-demo, combat stripped)
- Multi-user + VOIP
- Subliminal / multi-reality layers
- Always available, never required

### 3. World Model — LingBot Infinity
- Continuous real-time environment generation
- Procedural + persistent world state
- Dynamic scene updates from companion + user presence
- Feeds both classic and spatial modes

### 4. Haptics & Teledildonics (strictly opt-in)
- Buttplug.io / gspot
- Haptic suits
- Default = OFF
- One-click global disable
- Nothing locked behind hardware

### 5. Backend Brain
- HOPE / DREAM / VISION / KNOLL / APEX
- hdv-orchestrator (20,480-node topology)
- mistral-APEX-Nodes (persona inference)
- LingBot Infinity (world state)
- WebSocket bridge to Godot + web client

### 6. Compute — Google Colab
- Primary GPU for LingBot Infinity
- Heavy image / video / large model jobs
- On-demand notebooks orchestrated by backend
- Cost-controlled burst capacity

## User Rule
Everything works with zero hardware.
Hardware only adds an extra sensory layer when explicitly enabled.
